\begin{abstract}
Selecting an appropriate semantic segmentation model for a given application domain remains a challenging and time-consuming task for practitioners and researchers. This paper presents an interactive, web-based platform that enables side-by-side visual comparison of multiple neural network segmentation models applied to identical images. The system integrates three transformer-based segmentation models: a face-parsing network producing 19 semantic classes, a SegFormer-B3 clothing segmentation model with 18 classes, and a Mask2Former model for general-purpose scene segmentation spanning 150 ADE20K categories. Key contributions include side-by-side evaluation of model outputs across multiple architectures and image categories, with real-time segment highlighting and a scalable inference caching system that enables model comparisons without requiring repeated GPU computation. The platform organizes a curated dataset of images under a hierarchical category taxonomy, supporting structured evaluation across demographic and contextual variables. As a practical use case, the system is applied within the \ifthenelse{\boolean{anonymous}}{xxx}{ADRIAN} project to assist in verifying identity consistency across images through segmentation-based analysis. The platform is publicly available under xxx and designed to lower the barrier for comparative model evaluation in applied computer vision workflows.
\end{abstract}

\section{Introduction}
% ============================================================

Semantic image segmentation, the task of assigning a class label to every pixel in an image, has seen rapid progress driven by deep learning, with transformer-based architectures \cite{dosovitskiy2021vit} in particular achieving state-of-the-art results on standard benchmarks \cite{xie2021segformer}. However, the rapid growth of publicly available pre-trained segmentation models \cite{wolf2020huggingface, zhou2017ade20k}, each trained on different datasets and optimized for different domain assumptions, makes it increasingly difficult to identify the most suitable model for a given task without empirical comparison. A model that excels on face parsing may perform poorly on general scene understanding, and vice versa. Practitioners must therefore evaluate candidate models against their target data distribution before committing to a deployment choice.

Existing evaluation workflows are fragmented: researchers typically run inference scripts locally, produce static result images, and compare them manually \cite{abid2019gradio}. This process is labor-intensive, not easily shareable, and does not support interactive exploration of individual segment classes. There is a clear need for tooling that centralizes comparative evaluation in an accessible, visual, and reproducible manner.

\begin{figure}[htbp]
  \centering
  \includegraphics[width=\columnwidth]{screenshot.png}
  \caption{Screenshot of the platform showing a selected image compared across all three segmentation models. A segment is hovered, triggering the overlay highlight and a popup displaying the segment label and confidence score.}
  \label{fig:screenshot}
\end{figure}

This paper addresses that gap by presenting a web-based platform for the interactive comparison of segmentation models. The system allows a user to select an image from a curated, categorized dataset and immediately visualize the outputs of all three integrated models side by side on an interactive canvas. Individual segments can be explored via hover-based highlighting, with per-segment confidence scores and class labels displayed in real time. Additional segmentation models can be integrated with minimal effort and automatically appear alongside existing models for direct comparison.

The platform integrates three representative pre-trained models from the HuggingFace Hub \cite{wolf2020huggingface}: a face-parsing model \cite{jonathandinu_faceparsing}, a SegFormer-B3 clothing segmentation model \cite{sayeed99_segformer_b3}, and Meta AI's Mask2Former model fine-tuned on ADE20K \cite{mask2former_ade_hf}. These three models cover complementary segmentation granularities (facial anatomy, clothing and body parts, and scene-level objects), making cross-model comparison particularly informative for tasks that involve human subjects.


The platform was developed in the context of the \ifthenelse{\boolean{anonymous}}{\textbf{XXX}}{Authority-Dependent Risk Identification and Analysis in Online Networks (ADRIAN)} project \ifthenelse{\boolean{anonymous}}{[x]}{\cite{Baumer_Denisov_Geierhos_Su_Lee_2021}}, which is dedicated to \ifthenelse{\boolean{anonymous}}{xxx}{exploring and developing machine-learning-based methods for detecting potential threats to individuals based on online datasets and Digital Twins}. Within \ifthenelse{\boolean{anonymous}}{xxx}{ADRIAN}, segmentation models are used to extract and compare structural face and body features across image pairs, supporting identity consistency verification. The platform described here provides a dedicated environment for evaluating and selecting segmentation models suited to this verification task.

The main contributions of this work are:
\begin{itemize}
  \item An open, interactive web platform for side-by-side visual comparison of multiple semantic segmentation models on shared image inputs.
  \item An optimized canvas-based rendering pipeline with a downscaled label map enabling real-time hover-based segment inspection without redundant redraws.
  \item A batch segment retrieval endpoint and client-side cache that reduce HTTP round-trips per category load from $N \times M$ (images $\times$ models) to two requests.
  \item An extensible system architecture supporting heterogeneous model runtimes (Node.js Transformers.js and Python Flask), unified under a common REST API and result caching layer, allowing additional segmentation models to be integrated with minimal effort and compared directly against existing ones.
  \item A curated, hierarchically organized image dataset with demographic and contextual annotations, enabling structured evaluation across variables such as age, gender, accessories, lighting, and background.
\end{itemize}

Section~\ref{sec:models} details the integrated segmentation models. Section~\ref{sec:ui} presents the frontend and visualization design. Section~\ref{sec:dataset} characterizes the image dataset. Section~\ref{sec:discussion} addresses limitations and future work, followed by conclusions in Section~\ref{sec:conclusion}.

\section{Related Work}
\label{sec:related}

This section reviews prior work on semantic segmentation models and approaches to their evaluation and comparison.
% ============================================================

\subsection{Semantic Segmentation Models}

Semantic segmentation has evolved from fully convolutional networks \cite{long2015fcn} and dilated convolution approaches such as DeepLab \cite{chen2017deeplab} to encoder-decoder architectures \cite{ronneberger2015unet} and, more recently, transformer-based models. The SegFormer architecture \cite{xie2021segformer} introduced a hierarchical transformer encoder paired with a lightweight MLP decoder, achieving strong performance across multiple benchmarks while remaining computationally efficient. Several domain-specific adaptations of SegFormer have been published on HuggingFace \cite{wolf2020huggingface}, including models fine-tuned for face parsing \cite{jonathandinu_faceparsing} and clothing segmentation \cite{sayeed99_segformer_b3}.

Mask2Former \cite{cheng2022mask2former} advanced the state of the art by reformulating segmentation as a mask classification problem using a masked-attention Transformer decoder. Operating on multi-scale feature maps, Mask2Former achieves a mean Intersection over Union (mIoU) of 57.7 on ADE20K for semantic segmentation, a substantial improvement over the 37.4 mIoU reported for SegFormer-B0, while simultaneously supporting instance and panoptic segmentation within a single unified architecture.

Face parsing, the fine-grained labeling of facial regions such as eyes, nose, mouth, and hair, has been studied using methods ranging from CNN-based approaches \cite{lin2019face} to graph-based models and, recently, transformer fine-tunes. Clothing segmentation has similarly progressed with the release of large datasets such as CIHP \cite{gong2018cihp}, enabling models to distinguish among dozens of garment and body-part classes.

\subsection{Model Evaluation and Benchmarking Tools}

While standard benchmarks such as ADE20K \cite{zhou2017ade20k}, Cityscapes \cite{cordts2016cityscapes}, and COCO-Stuff \cite{caesar2018cocostuff} provide quantitative leaderboards, they do not support interactive, image-level qualitative comparison. Several visualization toolkits exist for inspecting model predictions (including Gradio \cite{abid2019gradio} and Streamlit-based demos), but these are typically single-model interfaces without structured dataset organization or persistent result storage.

Platforms such as Papers With Code \cite{paperswithcode} aggregate published benchmarks but do not provide an interactive environment for running inference on custom data. Our platform complements these efforts by offering a self-hostable, multi-model comparison environment with persistent caching, making it suitable for iterative evaluation in applied research settings.

\section{System Architecture}
\label{sec:system}
% ============================================================

The platform follows a three-tier architecture comprising a web frontend, a middleware layer, and a backend inference service, with a shared database for caching and metadata storage. Fig.~\ref{fig:architecture} illustrates the high-level system design.

\begin{figure}[htbp]
  \centering
  \includegraphics[width=\textwidth]{architecture.pdf}
  \caption{High-level system architecture. The frontend communicates with the backend through dedicated services. The backend routes inference requests to the appropriate model runtime and caches results to avoid redundant computation.}
  \label{fig:architecture}
\end{figure}

\subsection{Backend}

The backend exposes a REST API covering image management, category retrieval, model listing, and inference. When a segmentation result is requested, the server first checks the cache; if a result already exists, it is returned immediately without re-running inference. Otherwise, the request is dispatched to the appropriate model handler. A concurrency guard prevents duplicate inference jobs from being launched for the same image and model simultaneously.

To reduce loading times when a user browses a category, the backend provides a batch endpoint that returns all cached segmentation data for every image in the category and every registered model in a single request. This reduces the number of required frontend requests from one per image-model pair to just two per category switch, regardless of how many images the category contains.

\subsection{Inference Services}

The face-parsing model runs directly within the Node.js backend process, requiring no separate service. The clothing and scene segmentation models are handled by a dedicated Python inference server, which loads both models at startup and keeps them in memory for fast repeated use. Each model returns per-segment results including the class label, a confidence score, and a colored mask overlay.

\subsection{Offline Pre-computation}

The platform includes a pre-computation script that processes all images in the dataset with all registered models and stores the results in the cache. Once this has been run, no inference is performed during normal use: all pages load results directly from the database, making the platform fast and suitable for deployment without GPU access at runtime.

\subsection{Extensibility}

Adding a new segmentation model requires registering it in the database and providing a handler that returns results in the standard format. No changes to the frontend or database schema are needed, keeping the integration cost low.

\subsection{Clothing Segmentation Model}

The \texttt{sayeed99/segformer\_b3\_clothes} \cite{sayeed99_segformer_b3} model uses a SegFormer-B3 \cite{xie2021segformer} backbone fine-tuned for human parsing and clothing segmentation. Its 18 output classes include background, hat, hair, sunglasses, upper clothes, skirt, pants, dress, belt, left and right shoes, face, left and right legs, left and right arms, bag, and scarf. On the ATR dataset \cite{liang2015atr}, the model achieves a mean IoU of 0.69 \cite{sayeed99_segformer_b3}. This model is relevant for applications involving fashion analysis, person re-identification, and clothing-aware image retrieval.

\subsection{General Scene Segmentation Model}

The \texttt{facebook/mask2former-swin-large-ade-}\allowbreak\texttt{semantic} \cite{mask2former_ade_hf} model implements the Mask2Former architecture \cite{cheng2022mask2former} with a Swin-Large backbone \cite{liu2021swin}, fine-tuned on the ADE20K dataset \cite{zhou2017ade20k} covering 150 semantic categories. Mask2Former reformulates segmentation as a mask classification problem using a masked-attention Transformer decoder operating on multi-scale feature maps. On ADE20K, the model achieves 57.7 mIoU \cite{mask2former_ade_hf}. Its broad categorical coverage, spanning structural elements (wall, floor, ceiling), natural objects (tree, plant, water), and human-made objects (chair, table, car), makes it useful for understanding scene context surrounding subjects, complementing the face- and clothing-specific models.

\section{Frontend and Visualization}
\label{sec:ui}
% ============================================================

The frontend is implemented in Angular 17 \cite{angular2023} and organized into a comparison page (Fig.~\ref{fig:screenshot}) and a landing page (Fig.~\ref{fig:homepage}). The comparison page is the primary workspace, comprising an image and category selector, a comparison section, and a floating segment information panel.

\subsection{Canvas-Based Rendering}

Segmentation results are rendered on HTML5 canvas elements using a layered compositing approach. For each model result, the original image is first drawn onto the canvas, followed by the semi-transparent segment masks drawn in sequence on top. The per-segment PNG masks, stored as Base64-encoded strings, are decoded into \texttt{Image} objects and composited using the canvas 2D API with a global alpha value of 0.5, allowing the original image texture to remain visible through the overlay.

Original images and segment overlays are loaded concurrently: the original image begins loading immediately when the component is initialized, in parallel with the asynchronous segment data fetch. This ensures that the base image is displayed as soon as it arrives from the network, without waiting for inference results.

\subsection{Optimized Hover Interaction}

A key usability feature is segment-level hover highlighting: as the cursor moves over the canvas, the segment under the pointer is isolated and displayed with full opacity while all other segments are hidden. Implementing this interactively requires determining which segment covers each canvas pixel.

A naive approach, querying canvas pixel data on every \texttt{mousemove} event, would be computationally prohibitive for large images with many segment layers. Instead, the system constructs a \textit{label map} to enable real-time interaction: a downscaled (20\% of original resolution) integer array in which each entry encodes the index of the topmost non-transparent segment at that pixel location. This map is computed once per model result and stored in memory. On \texttt{mousemove}, the pointer coordinates are scaled into the label-map space and the segment index is retrieved in O(1) time without accessing the rendered canvas. This approach reduces memory consumption by 25$\times$ compared to a full-resolution map and maintains interactive frame rates even for the 150-class ADE20K model.

Two additional optimizations prevent unnecessary work. First, the handler compares the newly resolved segment index to the previously highlighted index; if they are equal, neither a canvas redraw nor an information panel update is triggered, eliminating redundant compositing when the cursor moves within the same segment. Second, canvas redraws are deferred to \texttt{requestAnimationFrame}, capping the redraw rate at the browser's display refresh rate and preventing frame-rate-exceeding renders when the cursor crosses segment boundaries rapidly.

Upon identifying the hovered segment, the component redraws the canvas by compositing only the original image and the highlighted mask, and updates the floating information panel with the segment's class label and confidence score.

\subsection{Category-Level Data Loading}

When the user switches to a new category, the frontend issues two parallel requests: one for the image list and one for all pre-computed segment data for that category. The segment data response is a nested map keyed by image ID and model ID, allowing the frontend to attach all inference results to their respective image objects before rendering begins. Components that receive a fully populated image object skip the individual inference request entirely, replacing $N \times M$ sequential fetches with a single batch response. For categories containing 20 images and 3 models, this reduces the number of HTTP requests from 60 to 2.

\subsection{Image and Category Management}

The platform supports uploading new images via a multi-part form. Fig.~\ref{fig:adding-image} shows the first step of this process, where the user provides the image URL and a display name. In subsequent steps, the image can be assigned to one or more undercategories in the hierarchy, and metadata including image origin, tags, and notes can be attached. Tags are intended to support a future search feature that will allow users to filter images across categories by arbitrary keywords. Existing images can be re-categorized or deleted. The category browser on the comparison page exposes the full two-level taxonomy, allowing users to filter the image gallery to a specific demographic or contextual subset before selecting images for comparison.

\section{Image Dataset and Taxonomy}
\label{sec:dataset}
% ============================================================

The platform ships with a curated set of approximately 120 images pre-loaded from Unsplash \cite{unsplash}, a source of openly licensed high-resolution photographs. The images were selected to cover a diverse range of subjects relevant to face and body segmentation tasks, including variation in age, gender, ethnicity, lighting conditions, accessories, backgrounds, and image style.

\section{Discussion and Limitations}
\label{sec:discussion}
% ============================================================

This section discusses performance characteristics, current limitations of the platform, and directions for future work.

\subsection{Performance Considerations}

Inference latency varies substantially across the three models and depends on hardware availability. The face-parsing model, executed via ONNX within the Node.js process, typically completes in under 2 seconds on a consumer CPU. The Python-based models benefit from GPU acceleration when available; on CPU alone, inference for the Mask2Former model can take 10-30 seconds for a standard image. The database caching layer and offline pre-computation script mitigate this for repeated queries: once all images have been pre-processed, the platform loads results directly from the database with no model inference at runtime.

\subsection{Model Coverage}

The current release integrates three models covering face, clothing, and scene domains. Important segmentation domains such as medical imaging, satellite imagery, and autonomous driving are not yet represented. The extensible architecture was designed to make adding new models straightforward, and we intend to expand the model registry in subsequent releases.

\subsection{Quantitative Evaluation}

The platform currently focuses on qualitative, side-by-side visual comparison. It does not include ground-truth segmentation masks for the pre-loaded dataset and therefore cannot compute standard segmentation metrics such as mIoU or per-class accuracy within the interface. Incorporating a ground-truth annotation mode is a planned enhancement that would transform the platform from a visualization tool into a full evaluation framework.

\subsection{Scalability}

SQLite is appropriate for single-user and small-team deployments but may become a bottleneck under concurrent multi-user load. Migrating the storage backend to a more scalable solution would be straightforward given the existing database abstraction layer.

\subsection{Model Integration Heterogeneity}

A practical challenge in building a unified comparison platform is that different segmentation models produce outputs in incompatible formats: they differ in how segments are represented, how confidence is reported, and whether masks are returned as dense label maps or as individual binary masks. The platform addresses this through a per-model adapter layer that normalizes all outputs to a common segment format before storage and display. This normalization cost is a recurring consideration when integrating new models and highlights a broader challenge in the field: the absence of a standardized output format for segmentation inference.

\subsection{Ethical and Privacy Considerations}

The image dataset is organized in part by demographic attributes such as age, gender, and ethnicity. While this taxonomy enables structured evaluation of model behavior across subgroups (for example, assessing whether a face-parsing model performs consistently across different skin tones), it also raises important ethical questions. Categorizing people by such attributes requires careful consideration of potential bias, fairness implications, and the risk of reinforcing stereotypes. All images in the platform are sourced from openly licensed repositories, and no personal data is stored. However, any extension of the dataset or use of the platform in contexts involving real user data should be conducted in accordance with applicable data protection regulations and ethical guidelines for research involving human subjects.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

We have presented a web-based platform for interactive, side-by-side comparison of semantic image segmentation models. The system integrates three transformer-based segmentation models spanning facial anatomy, clothing, and general scene understanding, and provides an intuitive canvas-based interface with real-time hover highlighting enabled by an efficient downscaled label map. A hierarchical image taxonomy supports structured evaluation across demographic and contextual variables, and a database caching layer with a batch retrieval endpoint ensures that inference results are reused across sessions and that category switches require only two HTTP requests regardless of dataset size.

The platform has been applied within the \ifthenelse{\boolean{anonymous}}{xxx}{ADRIAN} project as a practical tool for segmentation model selection in AI-manipulated image detection research. It is publicly available and designed with extensibility as a first-class concern, requiring minimal effort to integrate additional models.

By lowering the barrier to comparative segmentation evaluation -- eliminating the need for local model installations and providing immediate visual feedback -- the platform aims to accelerate the iterative model selection process in applied computer vision research. Future work will add ground-truth annotation support for quantitative mIoU evaluation, extend the model registry with additional domain-specific models, and explore real-time video segmentation as an interactive demonstration mode. Further planned enhancements include full-text search across categories and tags to improve dataset navigation, and the integration of AI-assisted image categorization to automate the assignment of demographic and contextual labels when new images are added.
